📖 Инструкция по установке

Linux / Kali:

tar -xzf darktrace-light-linux.tar.gz
cd darktrace-light
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
sudo python main.py

Windows:

1. Установите Npcap с https://npcap.com
2. Распакуйте darktrace-light-windows.zip
3. Запустите setup.bat (или вручную через PowerShell)
